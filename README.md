# The Data Visualisation Catalogue: Power BI Edition
The Power BI project files in this repo are used in my YouTube video series found here: https://www.youtube.com/playlist?list=PLZvdNpute2gw
Visit The Data Visualisation Catalogue: https://datavizcatalogue.com/index.html

The original Contoso dataset was sourced from SQLBI: https://www.sqlbi.com/tools/contoso-data-generator/
The dataset and semantic model are being enhanced by AI to support chart types that base dataset does not support.
All data is meant to be fictitious and is intended for education purposes only.
